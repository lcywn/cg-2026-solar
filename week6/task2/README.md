## 실습 2 장면 조작

`task2.html`을 HTTP 서버로 열면 두 슬라이더로 별과 작은 행성의 공전 거리를
조절할 수 있습니다. 별은 기존 거리가 최댓값이며, 작은 행성은 기존 거리가
중앙값입니다. 두 천체의 최소 거리는 중앙 행성과 겹치지 않도록 설정했습니다.
별의 높이는 가까워질 때 함께 낮아집니다. 화산과 얼음 표면 변화는 아직 구현되지 않았습니다.
공전 거리가 바뀌어도 각 천체의 이동 속도는 가장 먼 거리에서의 속도로 유지됩니다.
슬라이더의 0~100 값은 각각 최소~최대 공전 거리에 대응하며, 초기값은 별 100,
작은 행성 50입니다.
