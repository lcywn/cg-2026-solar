# 7주차 실습 2: 여러 기기의 렌더링 성능 비교

이 파일들을 자신의 GitHub 저장소 week7/ 폴더에 넣고 GitHub Pages로 배포합니다.
각 기기에서 자신의 Pages 주소의 week7/task2.html을 열어 측정합니다.
수업 자료의 캡처 화면이나 강의 홈페이지의 파일로 측정하지 않습니다.

공통 조건(640×360, 8표본, 2회 반사, 고급 효과 켬)과 고부하 조건을
PC·노트북·모바일 중 두 기기 이상에서 측정하고 보고서 week7.md에 분석합니다.
고부하 설정은 한 항목씩 높이면서 응답이 느려지는 경계를 찾으세요.

처음 접속할 때 데스크톱은 1920×1080, 32표본, 4회 반사로,
모바일은 960×540, 8표본, 1회 반사로 시작하며 모두 고급 효과가 켜져 있습니다.
설정을 변경한 후 「설정 저장하기」를 누르면 화면 방식과 모든 설정이
localStorage에 저장됩니다. 다시 저장하면 가장 최근 값으로 덮어씁니다.
「설정값으로 되돌리기」는 가장 최근 저장값을 다시 적용합니다.
「기본으로 되돌리기」는 저장값을 지우지 않고 처음 판별된 기기 유형의 기본
설정으로 되돌립니다. 마지막으로 저장하거나 복원한 설정 종류가 기억되므로,
기본으로 되돌린 후 새로고침하거나 다시 열면 기본 설정으로 시작합니다.
저장된 설정을 다시 적용하면 다음에도 저장된 설정으로 시작합니다.

저장값과 시작 설정은 같은 브라우저 프로필과 사이트의 탭·창에서 공유되며,
브라우저를 다시 실행해도 유지됩니다. 열려 있는 다른 탭은 새로고침하거나
복원 버튼을 누르면 공유된 설정을 적용합니다. 다른 브라우저, 프로필, 기기
또는 시크릿 세션과는 공유되지 않으며, 사이트 데이터를 삭제하면 사라집니다.
이전에 현재 탭의 sessionStorage에 저장한 설정은 처음 실행할 때 이관합니다.
브라우저의 기기 정보로 유형을 추정하므로 일부 기기에서는 잘못 분류될 수 있습니다.
