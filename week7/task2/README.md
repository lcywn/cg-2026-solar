# 7주차 실습 2: 여러 기기의 렌더링 성능 비교

이 파일들을 자신의 GitHub 저장소 week7/ 폴더에 넣고 GitHub Pages로 배포합니다.
각 기기에서 자신의 Pages 주소의 week7/task2.html을 열어 측정합니다.
수업 자료의 캡처 화면이나 강의 홈페이지의 파일로 측정하지 않습니다.

공통 조건(640×360, 8표본, 2회 반사, 고급 효과 켬)과 고부하 조건을
PC·노트북·모바일 중 두 기기 이상에서 측정하고 보고서 week7.md에 분석합니다.
고부하 설정은 한 항목씩 높이면서 응답이 느려지는 경계를 찾으세요.

처음 방문할 때는 모바일과 데스크톱의 시작값이 적용됩니다. 각 기기에서 실제
측정 결과를 바탕으로 화면과 설정을 조절하면 해당 브라우저의 localStorage에
저장되고, 다음 방문이나 새로고침 때 자동으로 복원됩니다. PC와 노트북은
자동으로 구별하지 않으므로 각 기기에서 적정 설정을 한 번씩 지정하세요.
스마트폰 여부는 브라우저가 제공하는 기기 정보로 추정하므로, 정보가 숨겨지거나
데스크톱 사이트 요청 등을 사용하는 경우 실제 기기와 다르게 판별될 수 있습니다.
저장소가 차단되거나 삭제되면 설정이 유지되지 않을 수 있습니다.
두 기기 모두 Pages에서 새로고침한 뒤 적정 설정이 적용되는지 확인하세요.
